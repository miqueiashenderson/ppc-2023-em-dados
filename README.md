# PPC 2023 em Dados

Repositório contendo os dados do PPC 2023 de Ciência da
Computação da UFCG. A ideia é reunir os dados tanto no formato
formal (PDF, tipicamente) como em formato apropriado para
manipulação programática. Também serão acrescentados dados de
atualizações (novas disciplinas optativas, basicamente).

O repositório diretório bin contém scritps usados para a extração
inicial (automatizada) e/ou manipulação de dados obtidos do
PPC.
